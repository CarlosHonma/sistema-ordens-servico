# Sistema de Ordens de Serviço

Aplicação em Python para gerenciamento de ordens de serviço, desenvolvida de forma incremental com foco em organização, boas práticas e simplicidade.

## Funcionalidades
- Cadastro de clientes
- Criação de ordens de serviço
- Listagem e finalização de ordens
- Persistência de dados em arquivo JSON
- Interface gráfica com Tkinter

## Estrutura do projeto
- `main.py`: interface gráfica e ponto de entrada
- `models.py`: classes e regras do domínio
- `services.py`: regras de negócio
- `database.py`: persistência de dados (JSON)

## Tecnologias
- Python 3
- Tkinter
- JSON
