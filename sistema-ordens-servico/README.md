# Sistema de Ordens de Serviço

Sistema simples de gerenciamento de ordens de serviço desenvolvido em Python, executado via terminal.

## Funcionalidades
- Criar ordens de serviço
- Listar ordens
- Finalizar ordens

## Estrutura
- `models.py`: classes do sistema
- `services.py`: regras de negócio
- `database.py`: armazenamento em memória
- `main.py`: execução do sistema

## Tecnologias
- Python 3
